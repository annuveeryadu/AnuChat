Welcome to the official website of AnuChat Android App.

AnuChat ek simple chat app hai. Number ya username se dost dhundho, live baat karo, aur galat message ko sabke liye delete kar do. Neeche wale phone me khud try karo.

Isme kya kya kar sakte ho

Apna account banao

Naam, username, Date of Birth aur 10 digit ka mobile number daalo. Bas, account taiyar.

Number ya username se dost dhundho

Dost ka mobile number ya username likho aur seedha chat shuru karo, ya use contacts me save kar lo.

Live chat

Dost online ho to tumhara message turant uske phone me aa jata hai, bina refresh kiye.

Online, offline aur unread

Chat list me dikhta hai ki kaun online hai, aur kis dost ke kitne naye message aaye hain.

Delete ke teen tareeke

Sabke liye delete: dono phones me “Ye message delete kar diya gaya” dikhta hai. Ye sirf wahi kar sakta hai jisne message bheja ho. Mere liye delete: message sirf tumhare phone se hatta hai. Poori chat delete: poori chat sirf tumhare liye saaf hoti hai, dost ki taraf waisi hi rehti hai.

Net gaya, app nahi ruki

Connection toot jaye to app khud dobara jud jati hai aur chat wapas le aati hai.

Purani chat hamesha saath

Chat kholte hi purani baatein dikh jati hain, dost offline ho tab bhi.

Password badlo

Menu me Password badlo se jab chaho naya password laga lo.

Sahi time

Har message ka time tumhare phone ke apne time ke hisaab se dikhta hai.
